# Phase 2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `wh` write settings the vendor configurator recognises as its own, move all persisted state to JSON, and fill in the missing read and management commands.

**Architecture:** Four-crate Rust workspace. `wh-proto` is a pure codec with no I/O. `wh-device` composes protocol commands into operations over a `Transport`. `wh-config` persists snapshots and key groups. `wh-cli` is the clap surface. Every change here follows that layering: new protocol constants and encoders go in `wh-proto`, new device operations in `wh-device`, new persistence in `wh-config`, and new commands in `wh-cli`.

**Tech Stack:** Rust 2021, clap 4, serde, serde_json, toml (read only after this plan), hidapi, ratatui/crossterm (picker only), thiserror, anyhow.

**Spec:** `docs/superpowers/specs/2026-08-29-phase-2-design.md`

## Global Constraints

- Commit messages are one line, `[type] - Message`, where type is one of `feat`, `fix`, `docs`, `test`, `refactor`, `chore`. No body. **No trailers of any kind, including `Co-Authored-By`.**
- No em dashes and no en dashes anywhere, in code, comments, docs or commit messages.
- Comments default to one or two lines. Four is the ceiling and must earn it. No references to review rounds, task numbers or chunk numbers: they cite a gitignored ledger and are dead pointers.
- `ReplayTransport` matches every outgoing frame against the script byte for byte. **Never loosen that match to make a test pass.** It defeats the entire harness.
- Never run a command against the real board during development. Set `WH_REPLAY`, and check the `transport: replay` line the CLI prints on stderr. A reviewer once performed a real write believing it was a replay.
- Never run `wh keys group` against the real user config while checking examples. Redirect `XDG_CONFIG_HOME`.
- Acceptance gate for every task: `cargo test --workspace`, `cargo clippy --workspace --all-targets -- -D warnings`, `cargo fmt --all --check`. All three must pass before commit.
- Baseline at the start of this plan: 222 tests passing.
- The board's four profiles are wire index `0..=3`, one-based `1..=4`.
- Protocol facts used here, all measured from `captures/`: MODE touch nibble 0 = Global, 1 = Single, 3 = Rt, 4 = RtContinuous. Nibble 2 has never been observed. Actuation point is layout `0x04`, MODE is `0x08`, rapid trigger press and release are `0x14` and `0x15`.

#[derive(Debug, thiserror::Error)]
pub enum ParseError {
    #[error("JSON parse: {0}")]
    Json(#[from] serde_json::Error),
    #[error("TOML parse: {0}")]
    Toml(#[from] toml::de::Error),
}

impl Snapshot {

        serde_json::to_string_pretty(self)
    }
    /// Retained only so the workspace builds until Task 3 moves the callers. Task 3 deletes it.

        toml::to_string_pretty(self)
    }
    pub fn from_json(s: &str) -> Result<Self, serde_json::Error> {
        serde_json::from_str(s)
    }
    pub fn from_toml(s: &str) -> Result<Self, toml::de::Error> {
        toml::from_str(s)
    }
    /// Parses by file extension: `.toml` for a pre-JSON backup, JSON for anything else.
    pub fn from_file_text(path: &Path, text: &str) -> Result<Self, ParseError> {
        if path.extension().is_some_and(|e| e == "toml") {
            Ok(Self::from_toml(text)?)
        } else {
            Ok(Self::from_json(text)?)
        }
    }
}

```rust
    fn config_path(&self) -> PathBuf {
        self.root.join("config.json")
    }

    /// Reads `config.json`, falling back to a `config.toml` written before the format change.
    /// JSON wins when both exist, since every write produces JSON.
    pub fn groups(&self) -> Result<HashMap<String, Vec<u8>>, StoreError> {
        #[derive(serde::Deserialize)]
        struct Cfg {
            #[serde(default)]
            groups: HashMap<String, Vec<u8>>,
        }
        let json_path = self.config_path();
        if json_path.exists() {
            let cfg: Cfg = serde_json::from_str(&fs::read_to_string(json_path)?)?;
            return Ok(cfg.groups);
        }
        let toml_path = self.root.join("config.toml");
        if toml_path.exists() {
            let cfg: Cfg = toml::from_str(&fs::read_to_string(toml_path)?)?;
            return Ok(cfg.groups);
        }
        Ok(HashMap::new())
    }

    pub fn set_group(&self, name: &str, usages: &[u8]) -> Result<(), StoreError> {
        let mut groups = self.groups()?;
        groups.insert(name.to_string(), usages.to_vec());
        self.write_groups(&groups)
    }

    /// Atomic write: land the content in a temp file, then rename into place, so a crash
    /// mid-write cannot truncate the config and drop every group the user defined.
    fn write_groups(&self, groups: &HashMap<String, Vec<u8>>) -> Result<(), StoreError> {
        #[derive(serde::Serialize)]
        struct Cfg<'a> {
            groups: &'a HashMap<String, Vec<u8>>,
        }
        fs::create_dir_all(&self.root)?;
        let text = serde_json::to_string_pretty(&Cfg { groups })?;
        let tmp_path = self
            .root
            .join(format!(".tmp-config-{}.json", std::process::id()));
        fs::write(&tmp_path, text)?;
        fs::rename(&tmp_path, self.config_path())?;
        Ok(())
    }
```

`write_groups` is factored out because Task 8 needs it for delete and rename.

/// Actuation point records for `usages`, matching what the vendor writes.
///
/// Writes layout `0x04` always, plus MODE with the touch nibble promoted from `Global` to
/// `Single`. Nibble 1 is the marker the vendor sets on every actuation point change, and the
/// reason a value written without it renders greyed in the configurator.
///
/// `Rt` and `RtContinuous` are left alone: an RT key still carries its own actuation point, so
/// a depth change must not turn rapid trigger off. Whether the vendor forces nibble 1 here is
/// unmeasured, so this takes the non-destructive reading.
pub fn ap_records<T: Transport>(
    s: &mut Session<T>,
    usages: &[u8],
    depth: Um,
) -> Result<Vec<KeyRecord>, DeviceError> {
    let mut out = Vec::with_capacity(usages.len() * 2);
    for &u in usages {
        out.push(KeyRecord {
            key: u,
            layout: layout::AP,
            value: depth.0,
        });
        let mode = Mode::from_value(read_layout_value(s, u, layout::MODE)?);
        if mode.touch == TouchMode::Global {
            let promoted = Mode {
                touch: TouchMode::Single,
                ..mode
            };
            out.push(KeyRecord {
                key: u,
                layout: layout::MODE,
                value: promoted.value(),
            });
        }
    }
    Ok(out)
}

    pub fn remove_group(&self, name: &str) -> Result<bool, StoreError> {
